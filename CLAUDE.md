## About this repository

Import of the original Xonix32 v2.51 by Shawn A. VanNess (1997–98, GPL),
preserved from the Internet Archive (https://archive.org/details/xonix-32).
Original C++/MFC source lives in `src/`; `Xonix32.dsw`/`Xonix32.dsp` are the
Visual C++ 6.0 project files. Treat the imported files as historical source —
don't reformat or modernize them unless asked.
